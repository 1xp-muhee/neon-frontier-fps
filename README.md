# Neon Frontier FPS

GitHub Pages에서 바로 실행되는 단일 페이지 FPS 훈련 게임입니다.

- `WASD`: 이동
- 마우스: 조준
- 클릭/스페이스: 발사
- `R`: 재시작

별도 빌드나 의존성 없이 `index.html`을 열면 실행됩니다.

## 2인 협동 모드

1. 한 사람이 `협동 방 만들기`를 누르고, 브라우저 주소의 `?room=` 링크를 상대에게 공유합니다.
2. 상대는 그 링크를 열어 `방 참가`를 누릅니다.
3. 호스트가 `훈련 시작`을 누르면 두 플레이어의 위치, 드론, 점수, 타이머가 동기화됩니다.

방 연결에는 PeerJS의 공개 P2P 시그널링을 사용합니다. 별도의 계정이나 서버 설정은 필요하지 않습니다.
